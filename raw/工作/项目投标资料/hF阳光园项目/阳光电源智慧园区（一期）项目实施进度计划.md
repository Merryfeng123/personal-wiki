## 五、关键路径分析（CPM，修正）

### 路径计算

| **路径**             | **构成**                                                                                                                 | **时长**               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------- | -------------------- |
| **软件关键（含物流12园区）**  | SW-01(1)+SW-02(3)+SW-03(3)+SW-04(1)+SW-05(3)+SW-07(1)+SW-08(2)+**SW-12物流(8)**+SW-16(3)+SW-17(3)+SW-18(2)+SW-19(2) 至W24 | **24周**（SW-12为软件最长支） |
| **硬件关键**           | HW-01(3)+HW-03(2)+HW-04(8)+**HW-05消防(8)**+HW-09(3)+HW-10(1)，起W3终W23                                                    | **21周（相对）→ 终点W23**   |
| **交汇后**            | 上线W24 + HW-12联调(4) + HW-13终验(2) + PM-04验收(W30–31)                                                                      | **至 W31**            |
| **保驾护航（非关键，独立时段）** | W24 → W48（6个月驻场）                                                                                                       | **24周，跨交期**          |

### 关键路径判定

**总关键路径 = 软件主线（SW-12物流12园区为最长支，共24周至W24上线）+ 联调终验（W24→W31，7周） = 31周（约7.1个月）**

* **建设+验收关键路径：W1 → W31（2026-09-21 → 2027-04-16，约7个月）**
* **9个月交期（W39 / 2027-06-18）前余量 8周（约20%缓冲）**
* **保驾护航 W24–W48（6个月）** 独立于交期承诺，SOW 硬性履行
* **质保 W31 起3年 → 2030-04**（竣工验收合格日起）

> **结论：关键路径因 SW-12 物流调度（12园区，8周）拉长，终点 W31 竣工验收；距9个月交期（W39）仍有8周浮动缓冲，进度可控。保驾护航与质保起算点已按"上线W24 / 竣工W31"正确分离。**
