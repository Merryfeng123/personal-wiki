## 二、把主线想清楚：我到底在做什么

这一整天的零散问题，其实只有**一条主线**：

> 把「树洞」从我自己电脑上的一个页面，变成**别人也能打开的东西**，然后让它被看见。

拆成四层，每一层的门槛完全不同：

```
① 自己做出来        —— 已完成（单文件网页 + 云服务后端）
② 别人能打开        —— 网页版【已通】；小程序【只通了一半】
③ 别人能长期用      —— 需正式小程序 + ICP 备案（未完）
④ 被看见 / 被评审   —— 1024 已投稿；小红书已发；公众号待发布；YouTube 待上传
```

**关键认知**：② 这一层是今天所有挫败感的来源——不是代码写错，而是**平台规则**在卡人。试用小程序发布出来是「体验版」，只有管理员自己能开；要给别人用，只有两条路：逐页审批体验成员，或者走正式小程序（个体户可以，但要备案，1–20 个工作日）。这个事实必须一次讲清，不能让她反复试。

## 三、以后判断问题的正确次序（今天验证有效的五条）

1. **先查本地，再下结论**。今天所有"是不是没做/没装/没配"的问题，答案都在本机文件里（配置、目录、数据库、设计资产）。说"未核实"是偷懒。
2. **分清三种"不行"**：① 我不会做 ② 我能做但平台不让 ③ 平台让但你没给我东西。今天的小程序体验权限属于 ②，AppID 缺失属于 ③。三种要给三种不同的回答，绝不能混成一句"做不了"。
3. **出片/做文档，先看既有资产**。审美判据存在文件里（设计卡片、历史成片、封面），不在我脑子里。今天视频沿用了绿白薄荷 + 宋体标题的既有视觉，一次过。
4. **验收只认证据，不认工具返回的 success**。上线要比 md5；公众号发布要回读草稿箱；视频要抽帧看画面；磁盘要 `df`/`du` 实测。今天有 3 处"看着成功其实没成"，全靠回读发现。
5. **动手前分清"读"和"写"**。磁盘这类事，先出只读报告 + 待确认清单，绝不自作主张删东西。

## 四、今天走过的坑（以后一项都不许再走）

| # | 症状 | 根因 | 正确做法 / 判据 |
|---|---|---|---|
| 1 | 小程序微信扫码登录报「无账号 / 该授权仅支持小程序账号」 | 走的是「绑定已有小程序账号」入口 | 必须选「**试用小程序**」。不是代码问题，重装重试都没用 |
| 2 | 小程序发布校验失败：`Couldn't resolve the Js file "@tencent-ai/workbuddy-cloud-sdk"` | 手搓 `miniprogram_npm/<scope>/<pkg>/` 缺扁平 `index.js`，试用小程序的打包器解析不了带 scope 的包 | 复制 SDK 到 `libs/wb-cloud-mp.js`，用**相对路径 require**；`setting.nodeModules=false`、`packNpmManually=false`，并删掉 `miniprogram_npm` |
| 3 | 公众号 API 发布一直 `48001 api unauthorized` | 未认证订阅号**没有** `freepublish` 接口 | 草稿进箱后只能**人工在后台点发布**。别再写脚本硬试，也别对她说"已发布" |
| 4 | 公众号草稿本地预览图片全空白 | `draft/get` 返回的正文里是 `data-src` | 预览时把 `data-src` 换回 `src` |
| 5 | 朋友扫码提示「没有体验权限」 | 试用小程序发布出来是**体验版**，仅管理员可用 | 要么对方「申请体验」由她在微信公众平台审批，要么直接给网页版。**这个权限我开不了**，不要假装能开 |
| 6 | zsh 里 `grep "a\|b"` 静默返回空，导致误判"代码里没有" | 反斜杠被 shell 吃掉 | 一律用 Grep 工具（ripgrep），不在 Bash 里写带转义的 grep 模式 |
| 7 | headless Chrome 连续被 `SIGTERM(137)` 杀 | 系统空闲内存只剩约 110MB | 内存紧张时不要硬上浏览器；改用 md5 / HTTP / 数据库只读校验取证 |
| 8 | Pillow 报 `ValueError: bad transparency mask` | `canvas.paste(img, pos, img)` 把 **RGBA 图当 mask** 用 | 用 `img.split()[3]` 作 mask，或全程 `alpha_composite` |
| 9 | 1080p 逐帧渲染跑到一半被杀 | 每帧都重算大模糊 + 全屏文本层 | 背景图、阴影、文本层全部**算一次缓存起来**，文本层只分配文字大小的小图。优化后 823 帧 / 69 秒 / RSS 126MB |
| 10 | 视频颜色发灰、播放器显示 `yuvj420p(pc)` | JPEG 序列直出被当成全范围 | 必须 `-vf "scale=in_range=pc:out_range=tv,format=yuv420p"` + `-colorspace bt709` |
| 11 | 以为"桌面已经同步进 iCloud" | `cloudDocs/Desktop` 只是**指向 `~/Desktop` 的符号链接** | 判断"是否已备份"不能看路径**长得像**，要 `ls -ldi` 看 inode / 是否 symlink。实测：桌面 52GB **零云端副本** |
| 12 | 差点去 Finder 删微信容器来腾空间 | 微信 `Containers` 目录是数据库 | 只能走微信「设置 → 通用 → 存储空间 → 管理」；Finder 直删 = 聊天记录整段损坏 |
| 13 | 手册里口令抄错、还写成"一次性" | 靠记忆复述 + 没查函数 | 口令以 `app_config` 原始值为准（md5 `c3efa44f`），**长期有效**（`claim_admin` 无作废逻辑）。改任何配置都要回库校验 |
| 14 | 把 4.45 万字符报成"9 万字" | 用字节数当字数 | 字数一律 `wc -m` |
