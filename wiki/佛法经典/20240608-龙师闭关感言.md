# 龙师闭关感言（2024-06-08）

> 来源：龙师 2024-06-08 闭关主题开示。原始资料含 77MB 视频与 60KB 逐字稿（docx），已存于 `raw/佛法经典/龙师说法/20240608-龙师闭关感言/`。视频不纳入 git（见 `.gitignore`），逐字稿为唯一可检索文本来源。

## 一句话概述
龙师以自身多次闭关（尤金刚乘）经验，系统讲解「闭关」实修的外部准备与日程次第——关房、结界、座位朝向、供具摆位、四座修法，并回应加行与法门选择的提问。

## 背景与缘起
- 龙师自述修过摩利支天菩萨法，整体接触密乘（男士）法脉较广，每次闭关主题不同，因涉秘法不便公开。
- 本场为面向学人的闭关实务开示，强调「和大家想象的不太一样」。

## 核心要点

### 1. 闭关与打禅七
- 长期（长期闭关）是闭关的一种；龙师仅打过一次长期，金刚乘闭关较多。
- 打禅七 = 克期求证，各法门闭关要求大体相同。可参考南师《阳山七日》及汉地大德闭关指南。

### 2. 关房选择
- 找非常干净、隐秘处；最好有独立厕所，避免外出。
- 不一定要在固定关房中，除非是**黑关**（绝对不能外出）。

### 3. 结界
- 分最内圈结界与最外圈（大）结界。
- 金刚乘通常在外侧以**金刚杵**立界，不出结界即可。

### 4. 座位与朝向
- 座位**面朝东方**最佳：东方表**升起次第**，本尊佛曼于东方升起；亦对应不动如来，能扫除障碍、积聚资粮。不便朝东时，可观想所朝方向为东。
- 座下铺**十字交叉金刚杵**（布/粉笔画均可），再放**吉祥草**（佛坐吉祥草悟道；实修中防潮防霉），保持座与地板间有空间利通风——宜用禅凳，勿坐堆杂物的床。

### 5. 供具与摆位
- 小桌按金刚乘仪轨：内供碗、外供碗、秘密供；置佛像/本尊形象/本尊石子。
- **右手边**：经书、法本、铃鼓等修法物；**左手边**：披单、保暖衣（便于取用）。

### 6. 四座修法（每日作息）
| 时段 | 内容 |
|---|---|
| 03:00–06:00 | 第一座 |
| 06:00–08:00 | 进食/饮茶（间隙） |
| 08:00–12:00 | 第二座 |
| 12:00–14:00 | 午休/午餐（日中一食） |
| 14:00–17:00 | 第三座 |
| 17:00–19:00 | 进食（间隙） |
| 19:00–21:00 | 第四座 |

## 关键问答
- **加行 vs 直接修准提法**：建议先完成加行——加行圆满即具「资粮道」，如子弹充足；有加行底子，日后转修任一法门（含密乘法、准提法）皆易上手、少障碍。
- **转识成智**：听众提问「当下觉知即智慧本性显现？常念持未达微细觉知」，龙师表示讲完闭关后再答（本逐字稿未见后续作答）。
